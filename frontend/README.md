# 🛡️ KAVACH-AI — Frontend Application

This directory contains the modern client-side user interface for **KAVACH-AI**, built using React 19, Vite, Tailwind CSS, and Framer Motion.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

The application will start at `http://localhost:5173`.

### 3. Build for Production
```bash
npm run build
```

## 🛠️ Tech Stack
- **Framework**: React 19
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Particle System**: `@tsparticles/react` & `@tsparticles/slim`
- **Icons**: Lucide React
